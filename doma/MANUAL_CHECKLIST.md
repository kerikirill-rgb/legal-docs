# Ручной чек-лист пилота «Дома»

Выполняется владельцем при наличии `BOT_TOKEN` и двух Telegram-аккаунтов.

## Подготовка

- [ ] `.env` с `BOT_TOKEN`, миграции применены, один процесс long polling
- [ ] Webhook снят (если был)
- [ ] Бэкап: `./scripts/backup.sh ./backups` отработал

## Сценарии

1. [ ] Аккаунт A: /start → создать дом → выбрать TZ и время → шаблоны
2. [ ] A: Настройки → пригласить → ссылка
3. [ ] Аккаунт B: открыть ссылку → увидеть название и имя → Присоединиться
4. [ ] Третий аккаунт / повтор ссылки / просроченный токен — отказ
5. [ ] A назначает дело B → B принимает / отказывает
6. [ ] Complete / На завтра / Другая дата / Предложить другому → согласие
7. [ ] Двойной клик «Сделано» — один цикл
8. [ ] Дождаться напоминания в выбранное время (или сдвинуть время на ближайшую минуту)
9. [ ] Перезапуск контейнера — данные на месте, нет лавины старых сводок
10. [ ] Покинуть дом / удалить дом / `/delete_me`
11. [ ] ИИ выключен — шаблоны; при включении — черновик и лимит
12. [ ] `doma-report <id>` без текстов сообщений
13. [ ] `./scripts/restore.sh` на копии БД (не на проде без бэкапа)

## Пилот

5 семей × 7 дней. Смотрим: оба участника активны к концу недели; меньше ручных напоминаний друг другу. Оплата Stars — отдельный этап.
