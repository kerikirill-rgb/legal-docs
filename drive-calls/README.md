# Drive Calls

iPhone-приложение для **очереди обзвона** за рулём: CSV → крупный экран контакта → звонок через обыную SIM → после разговора **«Дальше»** и разбор расшифровки → **Битрикс24** (входящий webhook).

## Телефония и запись (без Exolve API)

| Что | Решение |
|-----|---------|
| Исходящий звонок | `tel:` — обычный набор iOS, ваш личный номер МТС |
| Запись + текст | Услуга МТС [**«Интеллектуальная запись»**](https://support.mts.ru/servisi_voicetech/intellektualnaya-zapis/kak-podklyuchit-uslugu-intellektualnaya-zapis) — автоматически в «Мой МТС» (расшифровка и «итоги») |
| Связка с приложением | Публичного API у личного тарифа нет → после звонка **копируете расшифровку** в приложение («Вставить из буфера») или диктуете кратко в поле |
| Следующий номер | Таймер **10 сек** после этапа CRM → автонабор; **СТОП** (кнопка / голос «стоп») |

### Дорожная карта транскрипта (без «сложных допов»)

| Этап | Что делаем | Зачем |
|------|------------|--------|
| **1 (сейчас)** | МТС «Интеллектуальная запись» + **копипаста** в приложение | Быстрый тест на себе, ваш SIM |
| **2** | Тот же текст, но **Share → наше приложение** (iOS share extension) | Меньше шагов, всё ещё МТС |
| **3** | **Mango Office / Zadarma** — исходящий через SIP/WebRTC, запись и webhook на VPS | Без копипасты; тот же backend `/analyze` → Битрикс |

Переход на Mango **реалистен**: меняется только **источник текста** (webhook с `call_id` + URL записи), очередь и CRM остаются.

**Apple «Запись в Заметках»** (iOS 18+): встроенная запись в приложении «Телефон» → папка «Записи вызовов» в «Заметках». В **России регионально выключено**; смена региона Apple ID — костыль с рисками для оплаты и аккаунта, для продукта **не опираемся**.

**Запись в нашем приложении во время обычного `tel:`-звонка на iPhone невозможна** — iOS не отдаёт аудио сотового разговора сторонним приложениям ( только VoIP через CallKit).

## Структура

```
drive-calls/
  mobile/     # Expo (React Native) — UI на iPhone
  api/        # Node — анализ текста + REST Битрикс
```

## CSV

Первая строка — заголовки (латиница или русские подстроки):

```csv
phone,firstName,lastName,company,email
+79001234567,Иван,Петров,ООО Ромашка,ivan@example.com
```

## API

```bash
cd api
cp .env.example .env   # заполните переменные
npm install
npm run dev
```

- `POST /analyze` — `{ transcript, contact }` → `{ summary, actions[] }`
- `POST /execute` — `{ contact, actions[] }` → лид (поиск по телефону / создание), задачи, комментарий в таймлайне

### Битрикс

1. **Приложения → Ресурсы разработчика → Входящий webhook**
2. Права: `crm`, `task`
3. URL вида `https://YOUR.bitrix24.ru/rest/1/SECRET/` → в `BITRIX_WEBHOOK_URL` **без** имени метода в конце

Письма из приложения **не отправляются** автоматически — создаётся черновик в UI; отправку можно добавить через SMTP или `crm.activity.add`.

## Mobile

```bash
cd mobile
# укажите URL API, доступный с телефона (не localhost)
echo 'EXPO_PUBLIC_API_URL=https://your-api.example.com' >> .env
npm install
npx expo start
```

Сборка под iPhone: EAS Build или Xcode на Mac.

## Поток пользователя

1. Загрузить CSV.
2. **Позвонить** → на экране только **ФИО + компания** (фокус на разговоре).
3. МТС пишет разговор в «Мой МТС».
4. **Завершил разговор** → вставить расшифровку → AI → **Битрикс**.
5. **К следующему — 10 сек** → на экране следующий контакт, **СТОП** / голос «стоп» → автодозвон.

## Безопасность

Webhook Битрикс и `OPENAI_API_KEY` только на сервере. Не вшивайте секреты в мобильное приложение.
