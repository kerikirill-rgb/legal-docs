# Расклад Таро

1. Уточни вопрос, если он слишком общий (одной короткой фразой).
2. `check_access` — выбери допустимый тип расклада.
3. `draw_tarot_spread` с вопросом пользователя.
4. Структура ответа:
   - 1–2 предложения: энергия расклада в целом
   - По каждой карте: название, прямое/перевёрнутое, позиция, смысл для вопроса
   - Итог: практичный совет
5. `save_reading` с summary до 500 символов.

Стиль: образный, но понятный; без эзотерического жаргона без объяснений.
